# Glossary

* [Text](text.md) - The Datatype Ontology's `data:Text`: class to encapsulate a textual value. A `Text` holds exactly one `value`, a string.
* [Boolean](boolean.md) - The Datatype Ontology's `data:Boolean`: class to encapsulate a true-or-false value. A `Boolean` holds exactly one `value`, true or false.
* [Count](count.md) - The Datatype Ontology's `data:Count`: class to encapsulate an integer value. A `Count` holds exactly one `value`, an integer, and at most one `uncertainty`.
* [Quantitative Measure](quantitative-measure.md) - The Datatype Ontology's `data:QuantitativeMeasure`: class to encapsulate a quantitative measure value. A `QuantitativeMeasure` holds exactly one `value`, a decimal, exactly one `unit`, given by its IRI, and at most one `uncertainty`.
* [Quantitative Range](quantitative-range.md) - The Datatype Ontology's `data:QuantitativeRange`: class to encapsulate a quantitative range. A `QuantitativeRange` holds exactly one `min` and one `max`, decimals, exactly one `unit` and at most one `uncertainty`.
* [Percent](percent.md) - The Datatype Ontology's `data:Percent`: class to encapsulate a quantitative measure expressed as a percent value. A `Percent` is a `QuantitativeMeasure` whose unit is QUDT's PERCENT, `http://qudt.org/vocab/unit/PERCENT`.
* [Percent range](percent-range.md) - The Datatype Ontology's `data:PercentRange`: class to encapsulate a quantitative range expressed as in percent values. A `PercentRange` is a `QuantitativeRange` whose unit is QUDT's PERCENT.
* [Concept (data:Concept)](datatype-concept.md) - The Datatype Ontology's `data:Concept`: class to encapsulate a classifier, usually a values from a controlled vocabulary. A `Concept` holds exactly one concept by its IRI in `rdf_value`, RDF's `rdf:value`, and exactly one `vocabulary`, the IRI of the vocabulary it comes from. The adapt copy names the class `DatatypeConcept`, since LOKF defines `Concept`.
* [Value class](value-class.md) - In this repository, a class whose instances are values a knowledge concept holds, such as a measure or a range, and never concepts themselves. Every class of the Datatype Ontology is one, so a host imports them as the ranges of its own concept classes' slots.
