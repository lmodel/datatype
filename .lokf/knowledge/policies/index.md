# Policies

* [AI covenant](ai-covenant.md) - The repository's rules for work done with artificial intelligence (AI): you own what you submit; an element says what the Datatype Ontology says and cites its triple; a rule of this project's own is marked; no mapping is guessed; the ontology copy is never edited; and every element keeps the ontology's IRI.
* [Licence and attribution](license-and-attribution.md) - The licences: Apache-2.0 for the schema and the code, CC BY 4.0 for the knowledge bundle, and for the Datatype Ontology CC0 1.0 in its own metadata and CC BY 4.0 in its repository, of which NOTICE follows the stricter with an attribution to Simon Cox, CSIRO and the AGLDWG.
* [Security policy](security-policy.md) - How to report a vulnerability (GitHub's private vulnerability reporting), which release receives fixes (the latest), what executes in the repository and what holds each surface, the ruleset on `main`, and the two repository settings that are not yet in force.
